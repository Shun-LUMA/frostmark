# Welcome to Frostmark

A portable, read-only Markdown reader. **Your files stay untouched.**

## Getting started

Open a file with **Ctrl+O**, or drag it onto the window. Use the outline to navigate, and the preferences button to choose your theme and reading width.

> This document is also a formatting sample. Try changing the appearance or printing it.

## Code

```javascript
const message = 'A little space to read.';
console.log(message);
```

## Tables and tasks

| Shortcut | Action |
| :--- | :--- |
| Ctrl+O | Open a document |
| Ctrl+F | Find text |
| Ctrl+R | Reload from disk |
| Ctrl+P | Print / PDF |

- [x] Portable executable
- [x] Read-only documents
- [ ] Open your own Markdown

## Local links

Markdown links to other documents open in new tabs. Local images inside the document folder are supported. Remote images are blocked by default for privacy.

### Stay in control

Frostmark has no installer, automatic updater, analytics, or document uploads. Settings and its browser cache live beside the executable.
